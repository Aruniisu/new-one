# 🏫 School Management System

A comprehensive school management system built with Streamlit and Supabase.

## Features
- Student Management (CRUD)
- Teacher Management (CRUD)
- Development Officer Management (CRUD)
- Non-Academic Officer Management (CRUD)
- Advanced Search
- Reports Generation
- Bilingual Support (English/Sinhala)
